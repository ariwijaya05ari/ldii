# Absensi Pengajian — Frontend
Frontend statis (HTML/CSS/JS) untuk GitHub Pages. Backend: Google Apps Script (Kode.gs, dipasang terpisah).

1. Edit `js/config.js` → isi `GAS_URL` dengan URL `/exec`.
2. Folder ini = root repository. Jalankan `git init` DI SINI (folder yang berisi index.html).
3. Aktifkan GitHub Pages: Settings → Pages → branch main, folder / (root), Enforce HTTPS.
